# Python Service Overlay

Bu overlay, servis veya otomasyon odakli Python projeleri icin baslangic yapisi sunar.

Icerik:

- `demo/`: sade demo servis girisi
- `commercial/`: genisletilebilir private servis girisi

Ne zaman secilmeli:

- Backend veya automation Python ile yazilacaksa
- Demo ve commercial ayni runtime ailesini kullanacaksa
- Hafif ama duzenli bir baslangic isteniyorsa
