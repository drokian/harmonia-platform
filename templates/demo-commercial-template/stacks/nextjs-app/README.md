# Next.js App Overlay

Bu overlay, UI agirlikli urunler icin Next.js tabanli baslangic yapisi sunar.

Icerik:

- `demo/`: tanitim veya showcase web uygulamasi baslangici
- `commercial/`: private urun arayuzu baslangici

Ne zaman secilmeli:

- Web arayuzu ana urun yuzuyse
- Demo ve commercial ayni tasarim dilinden tureyecekse
- Hizli bir uygulama kabugu gerekiyorsa
