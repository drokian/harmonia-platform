# Stack Overlays

Bu klasor, base demo / commercial workspace template'inin uzerine uygulanacak teknoloji katmanlarini icerir.

Mevcut overlay'ler:

- `node-service`
- `python-service`
- `nextjs-app`

Kullanim:

1. Once ana template'i kopyalayin.
2. Ihtiyaca uygun overlay'i secin.
3. Overlay altindaki `demo/` ve `commercial/` dosyalarini ilgili repo koklerine kopyalayin.
4. Placeholder alanlari proje detaylarina gore guncelleyin.

Overlay mantigi bilincli olarak incedir: tam urun kurmaz, ama tekrar eden baslangic kararlarini hizlandirir.
