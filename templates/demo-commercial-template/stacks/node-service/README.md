# Node Service Overlay

Bu overlay, API veya backend odakli Node.js servisleri icin baslangic yapisi sunar.

Icerik:

- `demo/`: sade tanitim veya sandbox servis iskeleti
- `commercial/`: gelistirilebilir ana servis iskeleti

Ne zaman secilmeli:

- HTTP API gelistirilecekse
- Demo ve ticari taraf ayni backend paradigmasini paylasacaksa
- Baslangicta minimum bagimlilik isteniyorsa
