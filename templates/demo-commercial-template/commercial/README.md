# Commercial Repo Baslangici

Bu klasor, private commercial reposunun kokunu temsil eder.

Beklenen ozellikler:

- urunun ana veya musteriye ozel surumu
- lisansli icerik ve tam yetenek seti
- operasyonel ve teknik dokumantasyon

Bu template ile gelen temel alanlar:

- `src/`: ana urun kodu ve private moduller
- `src/agents/`: commercial'a ozel agent veya otomasyon kodlari
- `docs/`: architecture ve business-rules odakli belgeler
- `tests/`: unit/integration/regression testleri
- `scripts/`: build, deploy, migration scriptleri
- `config/`: ortama gore konfigurasyon dosyalari
