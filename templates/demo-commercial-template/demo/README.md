# Demo Repo Baslangici

Bu klasor, public demo reposunun kokunu temsil eder.

Beklenen ozellikler:

- sadelestirilmis ve guvenli icerik
- showcase veya tanitim odakli kurgu
- ayiklanmis dokumantasyon ve varliklar

Bu repo icine ticari lisansli, musteriye ozel veya hassas veri eklenmemelidir.

Bu template ile gelen temel alanlar:

- `src/`: demo tarafinda acik kaynaklanabilir is mantigi
- `docs/`: kullanim, ornekler ve API ozeti
- `tests/`: temel testler
- `scripts/`: demo otomasyon scriptleri
- `config/`: secret'siz konfigurasyon dosyalari
