# Demo Release Checklist

Bu liste, demo reposunda public yayin oncesi kullanilmalidir.

- [ ] Public paylasim icin uygun olmayan dosyalar temizlendi
- [ ] Demo README son kurulum ve kullanim adimlariyla guncellendi
- [ ] Ticari ozelliklere giden linkler ve yonlendirmeler kontrol edildi
- [ ] Hassas ortam degiskenleri ve sabitler kaldirildi
- [ ] Demo verileri anonim veya sentetik hale getirildi
- [ ] Ekran goruntuleri ve tanitim materyalleri guncel
- [ ] Lisans ve kullanim sinirlari acikca belirtildi
- [ ] Demo build veya calisma adimlari temiz ortamda test edildi
- [ ] Public repo etiketleri, aciklamasi ve gorunurlugu kontrol edildi
- [ ] Yayindan sonra takip edilecek sorun listesi hazirlandi
