# Commercial Release Checklist

Bu liste, commercial repo icin release veya teslim oncesi kullanilmalidir.

- [ ] Hedef musteri veya urun paketi kapsamı teyit edildi
- [ ] Gerekli lisansli dosyalar ve ozel moduller eklendi
- [ ] Ortam degiskenleri ve gizli anahtar akisi dogrulandi
- [ ] Dagitim notlari ve operasyon adimlari guncellendi
- [ ] Geriye donuk uyumluluk veya migration notlari hazirlandi
- [ ] Ticari entegrasyonlar ayri ortamda test edildi
- [ ] Hata izleme, loglama ve backup beklentileri teyit edildi
- [ ] Sorumlu ekip veya kisiye teslim notlari hazirlandi
- [ ] Etiketleme, versiyon ve degisim kaydi guncellendi
- [ ] Teslim sonrasi destek plani netlestirildi
