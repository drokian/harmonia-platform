# Development Workspace

Bu klasor, demo ve commercial repolari arasindaki ortak operasyon yonetimi icin kullanilir.

Ornek icerikler:

- gecis plani
- teslim checklist'leri
- release oncesi kontrol listeleri
- senkronizasyon notlari
- scaffold script'leri
- migration runbook dosyalari

Alt klasorler:

- `guides/`: uygulama ve operasyon kilavuzlari
- `checklists/`: tekrar kullanilabilir kontrol listeleri
- `migration/`: proje gecis planlari ve ornekleri
- `scripts/`: scaffold ve otomasyon script'leri
- `decisions/`: development seviyesinde karar notlari
- `templates/`: metin/dokuman sablonlari

Migration ornekleri icin `development/migration/` klasorunu kullanin.

Bu klasorun local kalmasi hedefleniyorsa, workspace koku git ile takip ediliyorsa kok `.gitignore` icinde hariç tutulmalidir.
