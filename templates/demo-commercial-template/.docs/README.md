# Workspace Docs

Bu klasor, workspace seviyesinde gecerli ortak dokumantasyon icindir.

Buraya alinabilecek icerikler:

- mimari karar kayitlari
- demo / commercial ayrim kurallari
- yayinlama ve operasyon notlari
- gecis planlari

Alt klasorler:

- `architecture/`: yuksek seviyeli tasarim, bagimliliklar, sinirlar
- `conventions/`: naming, commit, branch ve kod stili kurallari
- `workflows/`: release, hotfix, code review, incident surecleri
- `decisions/`: ADR benzeri karar kayitlari
- `glossary/`: ekipte ortak terim sozlugu
